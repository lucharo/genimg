# image-to-app

A back-and-forth in pictures: the agent shows, you pick, it narrows, then it builds.

> Use image-to-app: a mobile app for a shared grocery list.

1. **Directions.** You say what the app is for, mobile or web. The agent shows three to
   five visual directions for the main screen in one grid.
2. **Pick.** Choose one, or name the parts to combine.
3. **Views.** The agent breaks the pick into its screens (home, detail, settings) in the
   same style.
4. **Iterate.** Each round shows the set and asks a few numbered questions until every
   screen is accepted.
5. **Build.** The agent builds the app and checks it against the images on the platform you
   chose.

The questions come from Matt Pocock's
[grill-with-docs](https://github.com/mattpocock/skills/tree/main/skills/engineering/grill-with-docs),
which records decisions as you go. The skill offers to install it when missing.
